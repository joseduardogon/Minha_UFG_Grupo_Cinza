# Apps UFG

Lista fixa de aplicativos da UFG com abertura da Play Store.

- **Dono (autor):** Maicon Brendo da Silva
- **Revisor:** José Eduardo Gontijo de Carvalho
- **Prefixo de código dos itens:** `AppsUFG` (ex.: `DAtv-AppsUFG-01`)

Cada item de informação desta pasta é um par de arquivos com o mesmo nome:
`<TIPO>-AppsUFG-<nn>.md` (item preenchido a partir do [modelo](../Template-Item.md)) e
`<TIPO>-AppsUFG-<nn>.puml` (fonte PlantUML do diagrama). Itens sem diagrama (DD, Contrato, ECA) têm só o `.md`.
