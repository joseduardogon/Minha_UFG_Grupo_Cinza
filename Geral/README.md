# Modelos gerais

Artefatos do sistema inteiro: DCdu-Geral, DImp-Geral, DPac-Geral, DDados-Geral e DD-Geral.

- **Dono (autor):** Pessoa D
- **Revisor:** Pessoa C
- **Prefixo de código dos itens:** `Geral` (ex.: `DAtv-Geral-01`)

Cada item de informação desta pasta é um par de arquivos com o mesmo nome:
`<TIPO>-Geral-<nn>.md` (item preenchido a partir do [modelo](../Template-Item.md)) e
`<TIPO>-Geral-<nn>.puml` (fonte PlantUML do diagrama). Itens sem diagrama (DD, Contrato, ECA) têm só o `.md`.
