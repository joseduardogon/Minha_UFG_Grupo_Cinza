# Registros de uso de IA

Um arquivo por pessoa: `registro-A.md`, `registro-B.md`, `registro-C.md`, `registro-D.md`.
Cada uso registra IA (organização e ferramenta), URL, data de acesso e prompt completo (regra 6 do enunciado).
Prompts com mais de um parágrafo vão para o apêndice de prompts; a referência cita a seção do apêndice.
