# Tela inicial

Menu com os 8 cartões e a versão do app.

- **Dono (autor):** Pessoa D
- **Revisor:** Pessoa C
- **Prefixo de código dos itens:** `Inicio` (ex.: `DAtv-Inicio-01`)

Cada item de informação desta pasta é um par de arquivos com o mesmo nome:
`<TIPO>-Inicio-<nn>.md` (item preenchido a partir do [modelo](../Template-Item.md)) e
`<TIPO>-Inicio-<nn>.puml` (fonte PlantUML do diagrama). Itens sem diagrama (DD, Contrato, ECA) têm só o `.md`.
