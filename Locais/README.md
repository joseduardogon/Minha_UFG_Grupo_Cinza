# Locais

Lista de locais do Campus Samambaia, mapa com categorias e GPS.

- **Dono (autor):** Pessoa B
- **Revisor:** Pessoa A
- **Prefixo de código dos itens:** `Locais` (ex.: `DAtv-Locais-01`)

Cada item de informação desta pasta é um par de arquivos com o mesmo nome:
`<TIPO>-Locais-<nn>.md` (item preenchido a partir do [modelo](../Template-Item.md)) e
`<TIPO>-Locais-<nn>.puml` (fonte PlantUML do diagrama). Itens sem diagrama (DD, Contrato, ECA) têm só o `.md`.
