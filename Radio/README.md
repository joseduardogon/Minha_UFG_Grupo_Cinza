# Rádio

Programação semanal da Rádio UFG e abertura do player externo.

- **Dono (autor):** Pessoa D
- **Revisor:** Pessoa C
- **Prefixo de código dos itens:** `Radio` (ex.: `DAtv-Radio-01`)

Cada item de informação desta pasta é um par de arquivos com o mesmo nome:
`<TIPO>-Radio-<nn>.md` (item preenchido a partir do [modelo](../Template-Item.md)) e
`<TIPO>-Radio-<nn>.puml` (fonte PlantUML do diagrama). Itens sem diagrama (DD, Contrato, ECA) têm só o `.md`.
