# Segurança

Abertura da versão web e da Play Store para acionar a central de segurança.

- **Dono (autor):** Pessoa A
- **Revisor:** Pessoa B
- **Prefixo de código dos itens:** `Seguranca` (ex.: `DAtv-Seguranca-01`)

Cada item de informação desta pasta é um par de arquivos com o mesmo nome:
`<TIPO>-Seguranca-<nn>.md` (item preenchido a partir do [modelo](../Template-Item.md)) e
`<TIPO>-Seguranca-<nn>.puml` (fonte PlantUML do diagrama). Itens sem diagrama (DD, Contrato, ECA) têm só o `.md`.
